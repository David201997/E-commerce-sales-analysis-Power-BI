🛒 E-Commerce Customer Sales Analysis — Power BI

📊 Project Overview

This project focuses on analyzing e-commerce customer sales data using Microsoft Power BI. The objective is to transform raw sales data into meaningful business insights through data cleaning, analysis, interactive dashboards, and visualization.

The dashboard helps understand sales performance, customer behavior, product performance, revenue trends, and key business KPIs.

---

🎯 Objectives

- Analyze overall e-commerce sales performance.
- Identify top-performing products and categories.
- Understand customer purchasing behavior.
- Track revenue and order trends.
- Analyze sales across different regions.
- Identify important business KPIs.
- Create an interactive and user-friendly Power BI dashboard.
- Provide data-driven insights to support business decisions.

---

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query – Data cleaning and transformation
- DAX – Calculated measures and KPIs
- Data Modeling – Relationships between tables
- Microsoft Excel / CSV – Data source

🧹 Data Preparation

The data was prepared using Power Query. The main data-cleaning steps included:

- Removing duplicate records
- Handling missing values
- Correcting data types
- Renaming columns
- Creating calculated columns where required
- Formatting date fields
- Preparing data for analysis

---

🧮 DAX Analysis

DAX measures were created to calculate important business metrics and KPIs.

Example:

Total Sales = SUM(Sales[SalesAmount])

Total Orders = DISTINCTCOUNT(Sales[OrderID])

Average Order Value = DIVIDE([Total Sales], [Total Orders])
